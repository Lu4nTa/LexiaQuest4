# LexiaQuest

## 🇵🇹 Sobre o projeto

**LexiaQuest** é um jogo educativo 2D desenvolvido em **Godot Engine 4**, criado para apoiar a aprendizagem da língua inglesa por crianças com dislexia.

O projeto combina exploração, plataformas e quizzes de língua inglesa, aplicando princípios de acessibilidade e legibilidade estudados ao longo do trabalho.

## 🇬🇧 About the project

**LexiaQuest** is a 2D educational game developed using **Godot Engine 4**, designed to support English language learning for children with dyslexia.

The game combines exploration, platforming and English language quizzes, applying accessibility and readability principles explored throughout the project.

---

##  Características | Features

- 10 níveis | 10 levels
- Quizzes de língua inglesa | English language quizzes
- Suporte áudio | Audio support
- OpenDyslexic
- Plataformas e exploração | Platforming and exploration
